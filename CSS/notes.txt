CSS:
----
    ->CSS stands for cascading styles sheets used to apply stylings, layouts, animations to web page
    ->CSS are introduced in the year 1994 by the developer "Hakon wium lie "
    ->the present version of CSS is CSS3 
methods to apply stylings to web page:
--------------------------------------
 1.inline CSS /inline stylings:
 -----------------------------
     ->applying stylings by taking 'style attribute' in HTML elements
     ->this styling is applicable for only that element 
     ->for inline css not required css selectors
      ->inline stylings is more priority then internal and external CSS

 2. internal CSS /internal stylings:
     ->applying stylings by taking <style></style> tag in head part is called as a internal CSS/internal STYLINGS \
     ->to apply internal CSS we need CSS selectors 

 3.external CSS /external stylings : 
 --->apply styling by taking new.css file and link to html file by using <link></link> tag
 ->to apply external css we need css selectors 

CSS selectors:
-------------
  ->css selectors are used to target html elements to apply stylings
  ->css selectors are present only in internal and external css 

types of css selectors:
------------------------
 1.simple selectors:
      ->id selectors
      ->grouping selectors(,)
      ->universal selectors(*)
      ->class selectors(.)
      ->tag selectorsctors 
 2.combinator selector:
      ->descendent selector(space)
      ->child selector(>)
      ->adjacent sibling selector(+)
      ->general sibling selector(~)
 3.pseduo selectors :i.structure pseudo class selectors:
   
            1. ::after
            2. ::before 
            3. ::first-letter 
            4. ::first-line 
            5. ::maker
            6. ::selection 
            7. ::placeholder  


        Attribute Selectors : 
        ---------------------
            ->Attribute Selectors are used to target HTML Element based on attributes 

            Ex: <h1 algin="center" id="heading">  HELLO  </h1>
                <h1  id="heading">  HELLO  </h1>

                syntax:  selector[attributeName="value"]{
                                                        .... styling.....
                                                         }
            
            types: 
                1. [attributeName="value"] 
                2. [attributeName^="value"]
                3. [attributeName$="value"]
                4. [attributeName|="value"]
                5. [attributeName*="value"]
