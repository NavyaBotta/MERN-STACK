in js we can define variable in 3 ways:
--------------------------------------
1.let
->let variables act like an local scop/block scop
->variable declaration and initialization in same/different line is possible
->re-initialization is possible but re-declarationis not possible
->we can't hoist the let variables

2.var:
   ->let variables acts like a global scop (because var present in windows object)
   ->variable decleration and intialization in same /different line is possible
   ->re-initialization and re-declarationis is possible
->we can't hoist the var variables
